# Teaching datasets

This repository contains teaching code, but not the larger medical-imaging datasets used in class.

Some notebooks expect external teaching data such as pelvic MRI volumes, example NIfTI images, or the Medical Segmentation Decathlon spleen example. These datasets are intentionally excluded from the public repository to keep the portfolio lightweight and to avoid redistributing data without an explicit licence.

The notebooks use relative paths so the corresponding data can be placed alongside the repository in a local teaching environment. The small synthetic/measurement text files used in the visualisation examples are included.

For an interview, the repository can be reviewed without downloading the datasets: the notebooks show the teaching narrative, code, exercises, and representative saved outputs where available.
